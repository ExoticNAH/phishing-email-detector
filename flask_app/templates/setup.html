📘 How to Generate Gmail App Password

Gmail requires an App Password when external applications access your inbox securely.

  1. Enable 2-Step Verification in your Google Account
  2. Go to Google Account → Security
  3. Open or Search App Passwords
  4. Select Mail as the application
  5. Generate the 16-character password
  6. Paste the password in the field above
